# THE WORLD TODAY — 25 November 2026

A program that writes one image summing up the world's news of Wednesday
25 November 2026 to /output/entry.png.

## How it works

`main.py` (Python 3, standard library only) checks that `entry.png` is a
PNG file and copies it byte-for-byte to `$MAKEFUN_OUTPUT_DIR`
(default `/output`). The front page is pre-rendered: the grading sandbox
has no image library and no fonts, so the program does no rendering of
its own.
