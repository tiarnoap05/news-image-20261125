A newspaper front page summing up the world's news of Wednesday
25 November 2026 in one image.

`main.py` (Python, Pillow) draws the front page — masthead, lead story
on Pakistan's first astronaut aboard Shenzhou-24, the Kospi's 6.2%
plunge, and the day's other big stories — and writes it to
`/output/entry.png` (1024x1024). Deterministic: no clock, no
randomness, no network.

Run it:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
